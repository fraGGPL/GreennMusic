
# 🎵 Green Music

**Take control of your Minecraft music!**

Green Music is a client-side Minecraft mod built with Fabric. It allows you to manage Minecraft music, create custom playlists and enjoy a more personalized music experience.

---

## ✨ Features

- 🎶 **Music Control** – Play, pause, skip and return to previous tracks.
- 📀 **Custom Playlists** – Create, rename and manage your own playlists.
- 🎧 **Vanilla Music** – Browse and play Minecraft's original music tracks.
- 🔀 **Shuffle Mode** – Randomize your playlist.
- 📂 **Music Import** – Import your own audio files from your computer.
- 💾 **Playlist Saving** – Your playlists are stored locally.
- 🖥️ **In-game GUI** – Control your music directly inside Minecraft.
- 🎮 **Client-side Mod** – No server installation required.

## 📦 Installation

1. Install Minecraft Java Edition.
2. Install Fabric Loader for Minecraft 26.1.1.
3. Install Fabric API if required by the mod.
4. Download the latest Green Music release.
5. Put the `.jar` file into your Minecraft `mods` folder.
6. Launch Minecraft using your Fabric profile.

## 🎼 Playlists

Green Music lets you organize your music into custom playlists.

You can:
- Create playlists.
- Add and remove tracks.
- Switch between playlists.
- Reorder tracks.
- Use shuffle mode.

## 📂 Importing Music

Green Music is designed to support importing personal audio files from your computer.

Supported formats and conversion options depend on the release version.

## 🔧 Building from Source

Requirements:
- Java Development Kit (JDK) 25
- Gradle
- Fabric Loom

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd "green music"
```

Build the mod:

```bash
./gradlew build
```

The compiled `.jar` file will be located in:

```text
build/libs/
```
